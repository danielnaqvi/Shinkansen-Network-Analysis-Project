# Shinkansen-Network-Analysis

This project analyzes Japan’s Shinkansen high‑speed rail network using a Kaggle dataset. The goal was to explore station openings, line expansions, distances from Tokyo, and company ownership while building a polished SQL and Tableau portfolio piece.
I used SQL Server for data cleaning, exploration, and calculated fields, and Tableau for multi‑dashboard visualizations.

Tableau Dashboard: https://public.tableau.com/views/ShinkansenNetworkAnalysis/Dashboard1?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link

Dataset
Kaggle dataset: Shinkansen Stations in Japan
Includes:
- Station name (English)
- Line
- Year opened
- Prefecture
- Distance from Tokyo Station (km)
- Operating company

Project Overview
- Imported and cleaned the dataset in SQL Server.
- Explored station openings over time and line expansion patterns.
- Analyzed distances from Tokyo and geographic distribution across prefectures.
- Prepared data for Tableau using calculated fields and SQL queries.
- Built multiple dashboards showing timelines, maps, bar charts, and comparisons.

Techniques Used
- SQL data cleaning and type conversion
- Creating calculated fields for Tableau
- Joining and filtering station attributes
- Building multi‑view Tableau dashboards
- Visualizing timelines, maps, and distance metrics

Key Insights
- The Shinkansen network expanded in distinct waves, with major growth periods tied to national infrastructure initiatives.
- Lines vary significantly in their distance from Tokyo, reflecting regional development priorities.
- Prefectures along major lines show clusters of station openings during expansion years.
- Company ownership varies by region, with JR East, JR Central, and JR West dominating different parts of the network.
