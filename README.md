# Shinkansen-Network-Analysis

This project explores nearly six decades of Japan’s Shinkansen high‑speed rail network using SQL for data preparation and Tableau for visualization. The goal was to build a polished, portfolio‑ready dashboard that highlights network structure, geographic distribution, and historical expansion patterns

Tools: SQL Server, Tableau
